┌─────────────────────────────────────────────────────────────────────────────┐
│                    KONSEP OOP YANG DITERAPKAN                                │
└─────────────────────────────────────────────────────────────────────────────┘

  1. ABSTRAKSI
     └─ Kelas Kendaraan abstrak dengan method virtual murni (= 0)
     └─ Menyembunyikan detail implementasi

  2. PEWARISAN (INHERITANCE)
     └─ Motor, Mobil, Truk mewarisi dari Kendaraan
     └─ Mewarisi atribut dan method

  3. POLIMORFISME
     └─ Method hitungTarif() di-override di setiap kelas turunan
     └─ Runtime polymorphism dengan virtual functions
     └─ Satu interface, banyak implementasi

  4. ENKAPSULASI
     └─ Atribut protected (platNomor, pemilik)
     └─ Tarif disimpan private
     └─ Akses via method getter publik

  5. EXCEPTION HANDLING
     └─ Custom exception classes
     └─ Inherit dari std::exception
     └─ Method what() untuk pesan error

┌─────────────────────────────────────────────────────────────────────────────┐
│                      PERHITUNGAN TARIF                                       │
└─────────────────────────────────────────────────────────────────────────────┘

  Formula: Tarif = Tarif_Jam_1 + (Durasi - 1) × Tarif_Jam_Berikutnya

  Contoh Motor parkir 3 jam:
    = Rp 2.000 + (3 - 1) × Rp 1.000
    = Rp 2.000 + Rp 2.000
    = Rp 4.000

  Contoh Mobil parkir 4 jam:
    = Rp 5.000 + (4 - 1) × Rp 3.000
    = Rp 5.000 + Rp 9.000
    = Rp 14.000

  Contoh Truk parkir 5 jam:
    = Rp 10.000 + (5 - 1) × Rp 6.000
    = Rp 10.000 + Rp 24.000
    = Rp 34.000
